Permutation 4: 4fixedCG_freeD_fixedGaussians
============================================

Systematic question
-------------------
What phase is preferred by each spectrum when all trapped- and
superradiant-state shape parameters are prevented from moving?

FIXED
-----
- all Gaussian centroids and widths
- high-angle contaminant centroids and widths
- trapped centroid E_T
- trapped width Gamma_T
- superradiant centroid E_SR
- superradiant width Gamma_SR
- BG_E0 = 8 MeV

FREE
----
- all component FAC/yield parameters
- interference phase delta
- BG_A0 and BG_A1

Initialization
--------------
Every free parameter is seeded from the corresponding angle-specific
ground-zero best-fit solution.

Interpretive goal
-----------------
This is the strongest structural constraint in the angle-by-angle study.
With E_T, Gamma_T, E_SR, and Gamma_SR fixed, delta is the only free
Breit-Wigner shape/interference parameter. Comparison with Permutations 1-3
will show how much the phase uncertainty contracts when all structural
escape directions are removed, and whether the preferred phase itself
remains stable.
