Permutation 6: 6fixedET_freeGT_fixedES_GS_freeD_fixedGaussians
==============================================================

Systematic question
-------------------
How much phase uncertainty/covariance returns when only the trapped-state
width Gamma_T is released from the fully fixed Breit-Wigner structural model?

FREE
----
- trapped width Gamma_T
- interference phase delta
- all component FAC/yield parameters
- BG_A0 and BG_A1

FIXED
-----
- trapped centroid E_T
- superradiant centroid E_SR
- superradiant width Gamma_SR
- all Gaussian centroids and widths
- high-angle contaminant centroids and widths
- BG_E0 = 8 MeV

Initialization
--------------
Gamma_T and all other free parameters begin at the corresponding
angle-specific ground-zero best-fit values. All fixed Breit-Wigner parameters
remain at those same ground-zero reference values.

Interpretive goal
-----------------
Compare directly with Permutation 5. Permutation 5 isolated the contribution
from E_T. Permutation 6 isolates Gamma_T. The change in sigma_delta relative
to Permutation 4 quantifies how much trapped-width freedom contributes to the
phase uncertainty when all other Breit-Wigner structural parameters are held
fixed.
